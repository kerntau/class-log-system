# 班级日志管理系统

一个基于 Vue 3 + Vite 的前端课堂日志填报与审批演示系统，提供学生、辅导员和管理员三类角色的页面与权限流程。数据保存在 public/data/ JSON 文件中，首次加载后由浏览器内存缓存；仓库不包含后端服务。

## 功能概览

| 角色 | 能力 |
| --- | --- |
| 学生 | 填报日志、保存草稿、提交审批、撤回待审批日志、查看审批进度 |
| 辅导员 | 审批日志（通过/退回）、填写意见、查看班级日志 |
| 管理员 | 管理日志和通知、导入/导出 JSON、恢复初始数据 |

页面包括工作台、记录库、日志填报与详情、审批管理、通知、数据文件和个人资料。

## 技术栈

- Vue 3（Composition API、script setup）
- Vite 8
- Vue Router 4
- Lucide Vue
- 原生 CSS 变量主题系统
- JSON 文件 + 内存缓存（无后端依赖）

## 目录结构

    src/
    ├── components/       # 导航、弹窗、状态、列表等通用组件
    ├── data/             # 权限过滤、模拟数据与存储层
    ├── layouts/          # 审批、数据文件、日志模块布局
    ├── router/           # 路由与角色守卫
    ├── views/            # 工作台、日志、审批、通知和数据管理页面
    ├── App.vue
    └── main.js
    public/data/          # logs.json、notifications.json、users.json

## 本地开发

需要 Node.js 18+。

    npm install
    npm run dev
    # 按终端提示打开本地地址

生产构建与预览：

    npm run build
    npm run preview

## 数据与安全边界

这是一个前端演示项目，JSON 文件中的账号和日志均为示例数据。导入、导出和恢复操作只影响当前浏览器/静态部署副本，不提供服务端鉴权、并发控制或生产级数据持久化。部署真实业务前请接入后端身份认证、审计和数据库。

## 响应式设计

- 桌面端（>1024px）：双栏布局与完整导航
- 平板端（768–1024px）：单栏布局
- 手机端（≤768px）：汉堡菜单与触摸友好控件
- 小屏手机（≤480px）：紧凑间距和纵向卡片

项目未固定线上演示地址，请以自己的部署地址为准。
